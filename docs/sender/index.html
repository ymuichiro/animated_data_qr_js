How to run the sender

  1. Select the file you want to share.
  2. Choose the preset that matches your environment.
  3. Press Open QR stage to prepare the transfer automatically.
  4. Start the broadcast once the receiver is already scanning.
  5. Keep the modal visible until the receiver finishes.
